# 💱 Currency Converter Web Application

A modern and interactive **Currency Converter** web app that provides real-time exchange rates using API integration. Built with a clean UI and enhanced with smooth 3D animations for a better user experience.

---

## 🚀 Features

- 🌍 Convert between multiple global currencies
- 🔄 Real-time exchange rates using API
- 🏳️ Dynamic country flag updates
- 🎨 Modern 3D animated UI (glassmorphism)
- ⚡ Fast and responsive design
- 🖱 Interactive dropdowns and smooth animations

---

## 🛠️ Tech Stack

- **HTML** – Structure
- **CSS** – Styling (3D animations, glass effect)
- **JavaScript** – Logic, DOM manipulation, Fetch API
- **Currency API** – Real-time exchange rates
